# Núcleo SAT · Demo para el Trabajo Fin de Máster

Demo navegable de la interfaz de **Núcleo SAT**, el portal operativo del servicio técnico.

- **Abrir la demo:** https://javier-gagnay.github.io/nucleo-sat-demo-tfm/
- Todos los datos son **ficticios** (clientes, máquinas, técnicos, órdenes). La demo no se conecta a ningún sistema real: las respuestas se generan en el propio navegador.
- Rutas directas: añade `?route=/machine/RB48213`, `?route=/kanban`, `?route=/planning` o `?route=/copiloto` a la URL.

Sugerencia de recorrido: en *Inicio* busca la máquina `RB48213`, abre la orden `SO-10482`, consulta el stock de `CEP-4410`, revisa el *Kanban* y pregunta al *Copiloto*.
